# Panduan Pemain — Ular Tangga Nusantara Online

## Daftar & Login

1. Buka `/cahaya/` dan klik **MAIN SEKARANG**
2. Ikuti onboarding (bisa dilewati)
3. Pilih **Daftar** atau **Masuk** dari menu utama
4. Username 3–16 karakter, password minimal 8 karakter

## Cara Bermain

1. **PLAY ONLINE** — buat room atau gabung dengan kode
2. Tekan **READY** — host memulai permainan
3. **Lempar dadu** saat giliranmu
4. **Jawab soal** setelah berhenti di kotak
5. Hindari **ular**, manfaatkan **tangga**
6. Capai kotak **100** dan selesaikan Final Challenge

## Menjawab Soal

- Waktu terbatas (default 15 detik)
- Benar: lanjut bermain + XP
- Salah / timeout: mundur 10 kotak

## Bermain Online

- **Casual**: matchmaking atau private room
- **Ranked**: mempengaruhi RR dan tier rank
- Invite teman lewat menu **TEMAN**

## Rank & Reward

- **XP** dari jawaban benar, selesai match, menang
- **Coins** dari match dan achievement
- **Daily reward** — klaim dari profil
- **Leaderboard** — XP, Win Rate, Ranked

## Pengaturan

Menu **PENGATURAN**: audio, grafis, tema, ukuran teks, reduce motion, reset tutorial.

## Install PWA

Di browser yang mendukung, tombol **📲 INSTALL GAME** akan muncul. Game dapat diakses dari home screen (offline: halaman statis saja, multiplayer membutuhkan koneksi).

## Feedback

Menu **FEEDBACK** untuk melaporkan bug, saran, atau masalah soal.
